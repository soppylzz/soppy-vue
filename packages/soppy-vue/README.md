# soppy-vue

A Vue-like framework for learning and understanding the core principles of Vue.js.

This is the **public entry** package. It re-exports everything from `@soppy-vue/runtime-dom`, so a single import from `soppy-vue` gives you reactivity, runtime, and DOM rendering at once. It ships ESM (`dist/index.mjs`), CJS (`dist/index.cjs`) and an IIFE bundle for CDN usage (`dist/index.js`, global `SoppyVue`).
